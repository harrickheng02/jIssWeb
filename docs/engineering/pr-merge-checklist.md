# PR / 合并审阅检查单

面向本仓库贡献者：合并前自检与审阅者可对照的清单；**不**替代代码审查与团队约定。

## 合并前（作者）

- [ ] **关联**：PR 描述或评论中已关联相关 **pm-plan Issue**（若适用）与 **OpenSpec** 变更目录或归档路径（若适用）。
- [ ] **范围**：变更与 Issue / spec 描述一致；无无关大改。
- [ ] **自测**：已按变更类型做必要自测（前端 `npm test` / 构建、后端 `dotnet build` / 相关 API 等，按实际改动选择）。
- [ ] **CI**：确认针对目标分支的 **GitHub Actions**（若有）通过，或说明为何可延后（团队约定）。

## 审阅者

- [ ] 需求与实现、OpenSpec / 任务勾选（若适用）对齐。
- [ ] 受保护分支合入：在必过检查失败时**不**合并（与团队分支保护策略一致）。

## 说明

本清单为**人工**审阅辅助。可选本地 Git hooks 见仓库 **`.githooks/pre-commit`**（当前为占位，不强制校验）。
